# ITNT415 Calculator Master

**Student Name:** Justin Rich A. Galicha  
**Course and Section:** BIT 41  

## Project Description
A menu-driven Python calculator application developed using Git source control and GitHub branching workflows. The application performs addition, subtraction, multiplication, and division, featuring robust user input validation and zero-division exception handling.

## Branch Structure
- `main`: Core project structure and integrated application skeleton.
- `addition_Galicha`: Implementation and enhancement of addition functionality.
- `subtraction_Galicha`: Implementation and enhancement of subtraction functionality.
- `multiplication_Galicha`: Implementation and enhancement of multiplication functionality.
- `division_Galicha`: Implementation and enhancement of division functionality and zero-division handling.

## Program Features
- Menu-driven terminal interface with continuous loop execution until manually exited.
- Input validation for non-numeric characters.
- Division-by-zero error handling.
- Modular code structure using Python functions.
